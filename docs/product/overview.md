# 碎碎念

语气跟着钟点走：凌晨和深夜平静，早上和晚上温和，上午中午明快，下午活泼。每档里大约一半概率讲一段稍长的笑话。

同一句 3 小时内不会再说，当前语气的句子用完就换别的语气。预制的句子都说过了，就让模型接着写一句。模型知道你们聊过什么、你手上正在做的任务，还有你刚复制的那一条。

日常碎碎念默认 5 分钟一句，可以在[配置](configuration.md)里改。

# 说话和音效

每句台词都用 Fish Audio 合成语音播出来。固定台词可以预先合成好，天气这种当场才知道的句子第一次现合成，之后同一句直接用缓存。

每个动作同时放一段很轻的音效，大约是说话音量的两成：写代码是轻轻的按键，伸懒腰是一声拉长，发呆几乎听不见。不想要就关掉 `sfx.enabled`。

# 听你回应

打开听写（`listen.enabled`）后，碎碎念和模型现写的话说完，宠物会转过来面向你，听 5 秒。关掉就只说不听，想说话时再主动叫它。

听到的话先弹出一个确认页，发送按钮倒计时 3 秒。没人动就原样发送；动了鼠标、键盘或改了字，倒计时就停下，等你自己发送或取消。听起来像在问问题，yoyo 先搜一下再回答。

想主动说话，用右键菜单里的「听一句」，或按 Control+Option+Y。天气播报和闹钟说完不听。

# 右键对话

右键「对话」还是桌宠自己的输入框，但背后接的是 yoyo：它带上你们完整的对话记忆，不只是最近几轮。回复也会念出来。

模型的真密钥只留在 yoyo 里，桌宠拿到的是每次启动新生成的本机令牌。

# 记住你

打开记忆以后，yoyo 会记住你说过的、值得记的话：你的偏好和作息、手头的项目、提到的人、纠正过它的说法。每天夜里（缺省 3 点，你不在的时候）整理成一条条「记得的事」和一段画像，碎碎念和回复时带上。你可以随时看、随时删，见[日常使用](usage.md#记忆)。缺省关着，在[配置](configuration.md#记忆)里打开。

# 闹钟和日程

可以设每天、每个工作日、每周某天，或某一天一次。到点后 15 分钟内提醒一次。任务类的日程到点先说一句「到点了。」。

# 天气

工作日 17:00–18:59，每天先报一次接下来几小时的天气。地点第一次按系统时区自动选城市，选得不对可以手动改，见[数据](data.md)。不想听就关掉 `weather.enabled`。

# 表情包

空闲的时候，yoyo 会自己去找一套表情包。碎碎念大约四成会配上一张，天气和闹钟不配。不想要就关掉 `memes.enabled`。

# 不抢话

30 秒内还有别的对话或提醒，日常碎碎念就顺延到那些话停下之后 30 秒；中间又有人说话，就再往后让。

# 联系人

现在可以存下别人的名字和 yoyo 地址。以后用这个地址联系对方的 yoyo，现在还不会发起连接。
