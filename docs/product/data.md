# 位置

都在 `~/.yoyo`，`YOYO_HOME` 可以换。

| 位置                          | 内容                                                                                                 |
| ----------------------------- | ---------------------------------------------------------------------------------------------------- |
| `yoyo.db`                     | 对话记忆、联系人、日程、粘贴板（最近 50 条）、表情包、做过的事、说过的句子、本地任务、地点、天气日期 |
| `yoyo.db` 的 `agent_tasks` 表 | 子任务：目标、验收标准、todo、结果；子 agent 每一步记在对话记忆里各自的会话 `task:<编号>`           |
| `yoyo.db` 的 `memory_` 表     | 打开 `memory.enabled` 以后的记忆：笔记、记得的事、规矩、画像的每个版本                               |
| `speech-cache/`               | 合成好的语音                                                                                         |
| `sfx/`                        | 动作音效                                                                                             |
| `models/`                     | 听写模型，第一次用时下载；安装包从包里复制过来                                                       |
| `bin/yoyo-hotkey`             | 从源码运行时，第一次启动编译的按键助手；安装包用包里带的                                             |
| `config.json`                 | 安装包的配置；从源码运行时配置在 yoyo 目录                                                           |
| `pet.log`                     | 安装包开的桌宠的输出，每次开桌宠重写                                                                 |
| `app.log`、`app.log.1`        | yoyo.app 起的常驻进程的输出；过了 5 MB 打开时挪成 `app.log.1`                                        |
| `app.pid`                     | yoyo.app 开着时的进程号，更新时等它退出                                                              |
| `updates/`                    | 更新时下载、取出的新版和换版本的记录 `swap.log`，下次更新时清掉                                      |
| `inbox.jsonl`、`director.pid` | 命令和菜单交给常驻进程的请求；常驻进程的 pid                                                         |

# 记下什么

说过的话、听写、搜索、提醒、顺延、配音、加联系人、加日程、粘贴板变化，都记成一件「做过的事」。`pnpm yoyo log tail` 看最后 20 条。

* 记录里不写密钥。
* 粘贴板历史只是 yoyo 运行期间看到的变化，不是系统里更早的复制记录。`clipboard.enabled` 设为 `false` 就不读。
* 对话记忆保留原句，不截断。配了 `context.compactAt` 才会把较早的部分压成摘要，原文仍留在库里。
* 记忆只读对话记忆，不改它。碎碎念、天气、提醒不进记忆；粘贴板不进对话记忆，也就不进记忆。`pnpm yoyo memory forget <id>` 真删除一件记得的事，整理和删除也各记一件「做过的事」（删除只记 id）。删掉 `YOYO_HOME` 就什么都没了。

# 改地点

天气的地点第一次按系统时区选城市，认不出时区就按 IP 查。不对的话，写一份 `~/.yoyo/place.json`：

```json
{ "name": "台北", "latitude": 25.03, "longitude": 121.56 }
```

yoyo 下次打开数据时把它导进去。
